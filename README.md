# 霞沢涟的聊天框工作室：AstrBot 适配候选版

**状态：离线候选，未在真实 AstrBot 宿主或 QQ 中验收。** 请先在隔离测试实例使用，不要直接替换正在工作的机器人。原工作室不需要改动。

## 功能

- 插件设置里开启自动转图后，经过 AstrBot `on_decorating_result` 的 QQ 文字回复会尝试转为聊天框图片；默认关闭，默认只处理 AI 回复。
- 留空模板路径使用随包内置示例；填写运行环境可访问的 `.mscene` **绝对路径**可使用工作室模板。已用现有的多图层拼贴模板离线验证，不代表所有历史模板均已测试。
- 对话文本经标准输入传给本地渲染进程，不是命令行参数；不开启网络或调用生图模型。保留引用和 @ 的先后顺序。
- 任一文字段超过 240 字、模板无法读取、排版溢出或渲染失败时保留整条原消息。含图片、语音等混合媒体的消息暂时原样通过。
- 原型会保留收到的句末标点，因而和工作室默认隐藏框尾标点的效果可能不同。

## 安装到隔离实例

参考 AstrBot 官方方式，将本目录放入 `AstrBot/data/plugins/astrbot_plugin_chatframe/`，或尝试在插件页面选择从文件安装 ZIP；具体版本的加载和 ZIP 安装**尚未实测**。插件需 Python 和 Pillow；`requirements.txt` 记录依赖。当前只在 Windows、Python 3.12、Pillow 12.3 的本地渲染测试中验证。

在插件设置中将“自动将回复转为聊天框图片”打开。若使用自定义模板，填入 AstrBot 所在电脑或容器内的模板绝对路径。内置模板当前使用 Windows 系统中文字体；其他系统需先使用字体已嵌入的 `.mscene` 模板。

如果 AstrBot 是打包程序且默认解释器不能运行 Python 脚本，需要在插件设置中填写安装了 Pillow 的 Python 解释器绝对路径。

## 范围和待验收

- 只处理 `aiocqhttp`、`qq_official` 和 `qq_official_webhook` 的匹配事件；其他平台不处理。
- 本版依靠 AstrBot 的发送前钩子。流式输出、主动消息、其他插件直接调用发送接口等路径可能绕过它，尚未完成实际验证。
- 不直接发送、不重试发送；只是替换宿主待发送的消息链。已经进入 QQ 的图片是否成功到达，须由实际平台验收。
- 本地模拟测试覆盖开关、AI 结果、混合媒体、引用/@、失败回退及两套实际模板。AstrBot API 和异步传输为模拟，不等于真实宿主测试。
- 不会修改原始模板、聊天框工作室的工作区或现有机器人配置。自定义模板应包含它使用的图片和字体；图片、字体的使用许可由模板提供者确认。

渲染核心来自 [聊天框工作室公开源码](https://github.com/XIuMuBoZuo/chatframe-studio)。源码 MIT 许可及素材说明见 `renderer/licenses/`。
